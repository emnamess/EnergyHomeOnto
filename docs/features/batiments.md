# Feature 1 — Bâtiments et habitats

**Élève responsable :** à attribuer. Cette feature livre son propre frontend,
backend REST et ses requêtes SPARQL.

- Ontologie : bâtiments, maisons et sous-types, propriétés descriptives,
  consommation et équipement.
- Frontend : liste paginée, filtres, détail d’un bâtiment.
- Backend : endpoints `/api/batiments` et service SPARQL dédiés.
- Dépendances partagées : préfixe d’ontologie et format JSON convenus avec le
  groupe. Pas de modification unilatérale du vocabulaire partagé.
