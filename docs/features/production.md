# Feature 2 — Production énergétique

**Élève responsable :** à attribuer. Cette feature livre son propre frontend,
backend REST et ses requêtes SPARQL.

- Ontologie : `SourceEnergie`, sources renouvelables/non renouvelables, panneaux,
  éoliennes et centrales ; propriétés de puissance et d’émissions.
- Frontend : catalogue, détail et filtres par type et caractéristiques.
- Backend : endpoints `/api/sources` et service SPARQL dédiés.
- Dépendances partagées : préfixe et contrat de réponse communs.
