# Feature 5 — Territoires et acteurs

Un élève est responsable de cette feature verticale complète : frontend,
backend REST et requêtes SPARQL dédiées.

- Ontologie : `Zone`, `Quartier`, `Ville`, `Personne`, `Acteur` et
  `GestionnaireReseau`.
- Frontend : consultation et filtres géographiques et par acteur.
- Backend : endpoints propres et services/requêtes SPARQL dédiés.
- Contrats : partager le modèle JSON et les changements de vocabulaire via PR.
